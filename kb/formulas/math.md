#### 圆锥曲线
- 椭圆 x²/a² + y²/b² = 1（a>b>0），c² = a² − b²，e = c/a，离心率越小越接近圆
- 双曲线 x²/a² − y²/b² = 1，c² = a² + b²，e = c/a，渐近线 y = ±(b/a)x
- 抛物线 y² = 2px，焦点 (p/2, 0)，准线 x = −p/2；焦点弦长 = x₁ + x₂ + p
- 通径 2b²/a（椭圆、双曲线）；焦半径：椭圆 |PF₁| = a + ex₀，抛物线 |PF| = x₀ + p/2
- 弦长 |AB| = √(1+k²)·|x₁−x₂| = √(1+1/k²)·|y₁−y₂|
- 椭圆中点弦斜率 k = −b²x₀/(a²y₀)（点差法）；双曲线 k = b²x₀/(a²y₀)
- 离心率范围：椭圆 0<e<1，双曲线 e>1，抛物线 e=1

#### 直线与圆
- 点 (x₀,y₀) 到 Ax+By+C=0 距离 d = |Ax₀+By₀+C| / √(A²+B²)
- 弦长 = 2√(r² − d²)
- 圆的切线长² = 点到圆心距离² − r²
- 圆一般式 x²+y²+Dx+Ey+F=0（D²+E²−4F>0），圆心 (−D/2, −E/2)，r = ½√(D²+E²−4F)
- 两圆公共弦：两圆方程相减得直线；k₁k₂ = −1 ⇔ 垂直，A₁A₂+B₁B₂ = 0

#### 数列
- 等差：aₙ = a₁ + (n−1)d，Sₙ = n(a₁+aₙ)/2 = na₁ + n(n−1)d/2
- 等比：aₙ = a₁qⁿ⁻¹，q≠1 时 Sₙ = a₁(1−qⁿ)/(1−q)
- 错位相减、裂项相消、分组求和是常考三件事
- 等差：m+n=p+q ⇒ aₘ+aₙ=aₚ+a_q；S₂ₙ₋₁=(2n−1)aₙ；Sₙ/n 等差（公差 d/2）；分段和公差 n²d
- 等比：m+n=p+q ⇒ aₘaₙ=aₚa_q；Sₙ = Aqⁿ−A（q≠1）；分段和公比 qⁿ
- 求通项：aₙ₊₁−aₙ=f(n) 累加；aₙ₊₁/aₙ=f(n) 累乘；aₙ₊₁=paₙ+q 构造 aₙ+q/(p−1)
- 裂项：1/[n(n+1)] = 1/n − 1/(n+1)；数学归纳法：验 n=1 + 假设 n=k 证 n=k+1

#### 导数
- (xⁿ)' = nxⁿ⁻¹，(sinx)' = cosx，(cosx)' = −sinx，(eˣ)' = eˣ，(lnx)' = 1/x
- 切线：y − f(x₀) = f'(x₀)(x − x₀)
- 单调性看 f' 符号；极值点先解 f'=0 再验两侧变号
- 复合函数链式法则：[f(g(x))]' = f'(g(x))·g'(x)；(aˣ)' = aˣln a，(log_a x)' = 1/(x ln a)
- 求最值流程：定义域 → f' → 单调表 → 极值 → 端点比较
- 常用不等式：eˣ ≥ x+1（x=0 取等），ln x ≤ x−1（x=1 取等）

#### 空间向量
- cos⟨a,b⟩ = a·b / (|a||b|)
- 线面角 sinθ = |a·n| / (|a||n|)（a 方向向量，n 法向量）
- 二面角 cosθ = n₁·n₂ / (|n₁||n₂|)，注意判断锐钝
- 点面距离 d = |AP·n| / |n|；线线角、线面角范围都是 [0°, 90°]，二面角 [0°, 180°]

#### 三角函数
- sin²x + cos²x = 1，sin2x = 2sinxcosx，cos2x = cos²x − sin²x = 1 − 2sin²x
- 正弦定理 a/sinA = b/sinB = c/sinC = 2R；余弦定理 a² = b² + c² − 2bc·cosA

#### 概率统计
- E(X) = Σxᵢpᵢ，D(X) = Σ(xᵢ−E)²pᵢ = E(X²) − E(X)²
- 二项分布 X~B(n,p)：E = np，D = np(1−p)
- 正态分布：对称性 + 3σ 原则
