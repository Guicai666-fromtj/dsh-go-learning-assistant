# 学习助手·数学笔记规范（v1）

> 本文件是写笔记的执行标准，不本身是笔记内容。写之前先看完。

## 一、这批笔记干什么用

1. 学生（天津高二，人教A版）期末复习时能直接看、能背、能照着做题。
2. 助手（学习助手）以后出题、讲题、排复习、归类错题时当知识底稿。
3. 会导入 DeepTutor「数学笔记」知识库做检索问答，所以**分节要清楚、关键词要写全**（比如「错位相减法」「点差法」「二面角」这些词必须在正文里出现，别只写「这个方法」）。

## 二、文件格式（严格照这个来）

```markdown
# <章节名>（人教A版·选必X 第X章）

> 一句话说明这份笔记覆盖什么、适合什么时候看。

## 1. <小节点>
**核心**：定义、公式、二级结论（用列表，一条一个结论，别写成大段散文）
**怎么考**：常见题型 + 解题步骤（编号 1.2.3.）
**例**：（可选，最多 1 道；给题、给答案，解析两三步就够）
**易错**：坑在哪、考场提醒
[来源 BV1xxxxxxx P3 12:30]

## 2. ...
...

## 覆盖清单

| 课本小节 | 是否覆盖 | 备注 |
|---|---|---|
| 4.1 数列的概念 | ✅ | 视频 P2 |
| 4.2.1 等差数列 | ✅ | ... |

## 来源

| 视频 | BV号 | 分P | 时长 | 用到的段落 |
|---|---|---|---|---|
| 一数·xxx | BV1xxxx | P2 | 25m | 全片 |
```

要求：
- 每个 H2 小节**必须**带至少一个 `[来源 BV... P... mm:ss]`，时间码从字幕原文里取，不许自己编。
- 「核心」里的公式要能直接拿去用；二级结论标明适用条件（如「q≠1 时」「n≥2 时」）。
- 「怎么考」写给做题的人看，步骤要能照做，不要空话。
- 文末「覆盖清单」按课本小节自查，没覆盖的写 ❌ 并说明原因（如视频没讲、留到下一篇）。
- 全长 2500–4500 字（不含来源表）。宁可少而准，不许凑字数。

## 三、数学写法

- 用 Unicode 数学符号：aₙ、Sₙ、²、³、√、≤、≥、≠、∈、⇒、⇔、∑、×、·、±。
- 分数线用 / 或「分之」，复杂式子用括号写清楚，例：`Sₙ = n(a₁+aₙ)/2`。
- 下标统一用 aₙ、a₁、a_{n+1}（花括号只在多字符下标时用）。
- 中文标点，公式前后留空格，手机上好读。
- 不写 LaTeX 源码块（`$$`、`\frac`），DeepTutor 检索和手机阅读都不友好。

## 四、防编造（红线）

1. **只写视频里讲到的**。视频没讲的，要么不写，要么标明「课本补充」并确认是高中课本内容。
2. 字幕是机器转写，公式常错（会把 aₙ 转成「an」、把 q 转成「Q」）。要按数学逻辑还原，还原不了的整句不写。
3. 时间码、BV 号、分P、标题必须来自工具返回，**不许估**。
4. 例题：视频里有原题就抄视频的；没有就自己编一道同类题并标「自编例题」。自编题必须算对、答案自洽。
5. 一数视频里如果有口误/讲错，按正确数学写，并在「易错」里点一句「视频此处口误」。拿不准就不下结论。

## 五、bili_watch 怎么用（本机）

本机没装 ASR/OCR 依赖，**只能走字幕**。没字幕的视频直接跳过，换有字幕的。

1. `open_tool("bili_watch")` 打开工具。
2. 先 `search` 找视频，或直接用我给候选 BV。
3. 取字幕全文：
   `bili_watch(command="text", bv="BVxxxx", p=2, head=300)`
   - `head` 只回开头，返回里会给「全文已存」的路径（在 `/root/.dsh/bili-watch/cache/...`）。
   - 用 read 工具分段读那个全文文件（每次 800–1200 行），别重复跑命令。
   - 需要纯文本带时间码的，加 `format="md"` 或 `format="txt"`。
4. 如果返回「字幕: miss / 无字幕轨」→ 换视频，别硬跑 ASR。
5. 一次只处理一个分P；多 P 视频用 `p=` 指定。
6. 视频太长（>60 分钟）可以先看 `view` 的简介/热评判断值不值，再决定读多少；读的时候可以只读关键段落（按字幕里的「第几题」「下一个」跳读），但结论必须来自原文。

## 六、写完怎么交

1. 笔记写到指定文件（路径在任务里），**不要动别的文件**。
2. 自查：
   - 每个 H2 都有来源时间码；
   - 覆盖清单没漏课本小节；
   - 没有 `$$`、没有「如上所述」这类空话；
   - 字数在范围内。
3. 回报格式（发回给 lead）：
   - 文件路径 + 实际字数
   - 用了哪几个视频（BV、分P、时长）
   - 覆盖了哪些课本小节、哪些没覆盖
   - 发现字幕错得厉害/视频缺内容的地方，列 1–3 条
