# B 站网课 → 知识点笔记 → 知识库

详细流程见 `kb/notes/_扒课SOP.md`，笔记格式硬规矩见 `kb/notes/_规范.md`。本技能只列动作顺序和红线。

## 触发

用户给视频标题/链接/BV 号，或者贴一个收藏夹/合集，说「扒下来 / 整理成笔记 / 存知识库 / 学这个」。

## 步骤

1. **确认范围**：视频主题、对应课本哪一章、要几篇笔记（一篇一主题，别一锅炖）。
2. **取材料**
   - `bili_watch` 查视频信息、有没有字幕；有字幕先取全文（2023 年后视频一般有）。
   - 没字幕才转写：`python bin/asr-sensevoice.py --bv BVxxxx --p N --start 0:00 --end 30:00 --out /tmp/x.txt`
   - 板书/公式/角标看不清：`look.mjs sheet` 抽帧，直接看图；印刷体可 OCR 交叉核对。
3. **核对**：数字、下标、字母按数学常识还原（「十3」=13、「AN」=aₙ）；字幕错得离谱的句子不写进笔记。
4. **写**：H1 + 每节「核心 / 怎么考 / 例 / 易错」；每个知识点标 `[来源 BV... P... mm:ss]`；文末覆盖清单 + 来源表。禁用 LaTeX，数学用 Unicode。
5. **质检**：每节有来源；无 LaTeX；覆盖清单如实（缺哪节写哪节）；自编例题标注。
6. **入库（可选）**：`cd <DeepTutor 数据目录> && deeptutor kb add <库名> -d 文件1 -d 文件2`，再 `deeptutor kb search` 验收。没装 DeepTutor 先按 `AGENTS.md` §8.0 装好并配 embedding。

## 红线

- 只写视频讲到的；没讲到的不补、不猜。
- BV 号和时间码不许估；引用的视频必须真的能放。
- 笔记是自用学习材料，别把整段字幕原文搬运出去。
- 不覆盖用户已有的笔记文件；同名先问。
